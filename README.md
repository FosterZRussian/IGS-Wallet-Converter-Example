# Пример автоматического конвертера валюты для InGameShop (IGS) 
[![GitHub Stars](https://img.shields.io/github/stars/FosterZRussian/IGS-Wallet-Converter-Example?style=flat)](https://github.com/FosterZRussian/IGS-Wallet-Converter-Example/stargazers)

Пример автоматического конвертера донат-валюты по игровым наборам для [InGameShop](https://github.com/GM-DONATE/IGS) на случай, если не хотите использовать встроенный магазин товаров IGS или есть необходимость в прямой конвертации доната в свою игровую валюту сервера.

## Обратите внимание
> Меню показанное на фотолупах не идет в комплекте.

> ❗ Это лишь пример, основанный на моем личном проекте. Для вашего игрового сервера вам необходимо использовать свои функции для выдачи уведомлений/игровой валюты игроку (**svdb.players.GiveWallet**, **ply:ShowMsg**)
